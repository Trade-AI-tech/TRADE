## สิ่งที่พบ

1. **Order Block — หัวใจของ SMC — ไม่ได้อะไรเลยบนทอง** ทั้ง 1H และ 1D ไม่ดีกว่าการเข้าเวลาสุ่ม
   (p 0.40–0.71) · 1H ติดลบทุกรุ่น
2. **กวาดสภาพคล่อง + CHoCH (โมเดลกลับตัวที่ตำราชอบที่สุด) เกิดน้อยเกินจะวัด** — 11 ครั้งใน 23 เดือนบน 1H,
   8 ครั้งใน 21 ปีบน 1D
3. **FVG ตามเทรนด์ + ขยาย SL เป็นสิ่งที่ดีที่สุดที่โปรเจกต์นี้เคยวัดได้**
   - 1H: **+0.109 R/ไม้** · ช่วง 95% **+0.002 … +0.210** (ไม่คร่อมศูนย์ ก่อนปรับ) · p = 0.040
   - ดีกว่าการเข้าตามเทรนด์เวลาสุ่ม (p = 0.015) → ตำแหน่ง FVG มีข้อมูลเกินกว่าการตามเทรนด์
   - 1D ไปทางเดียวกัน: +0.095 R (695 ไม้ · p = 0.126)
   - บวกทั้งช่วง train และ validation ของทั้งสองกรอบ (บรรยายเท่านั้น ไม่ใช่การทดสอบ):
     1H +0.123 / +0.072 · 1D +0.103 / +0.071
4. **แต่ไม่รอด Holm** — p ต่ำสุด 0.040 ต้องต่ำกว่า 0.0042 (ทดสอบ 12 เซลล์)
5. **ต้นทุนตัดสินอีกแล้ว** — FVG แคบ SL จึงแคบ ต้นทุน 0.177 R กินขอบ +0.083 หมด พอขยาย SL จนต้นทุน
   เหลือ 0.047 R ผลพลิกเป็น +0.109 (กลไกเดียวกับทุกผลลบในโปรเจกต์นี้ — `costs.ts`)

## ข้อควรระวัง

- **แรงบวกทั้งหมดมาจากฝั่งซื้อ** — 1H ซื้อ +0.221 / ขาย −0.072 · 1D ซื้อ +0.234 / ขาย −0.110
  ทั้งสองช่วงข้อมูลคือช่วงที่ทองขึ้นใหญ่ (2000–2021 และ 2024–2026) ตัวเทียบ "สุ่มตามเทรนด์" คุมทิศไว้แล้ว
  จึงหักล้างเทรนด์ไปได้ส่วนหนึ่ง แต่ถ้าทองเปลี่ยนเป็นขาลงยาว ยังไม่มีข้อมูลบอกว่าจะเป็นยังไง
- **ขนาดข้อมูลตรวจได้เฉพาะผลที่ใหญ่** — SE ≈ 0.053 R ต่อค่าเฉลี่ย ผลที่จะรอด Holm ด้วยกำลัง 80% ต้องใหญ่
  ราว 0.20 R/ไม้ ผลที่เห็น (+0.11) เล็กกว่านั้นครึ่งหนึ่ง
- **ชุด test ช่วยได้ไม่มาก** — 1H มีแค่ ~6 เดือน (~140 ไม้) ถ้าผลจริงคือ +0.11 R โอกาสที่ชุด test จะให้
  p < 0.05 มีราว 20–30% (สองทาง/ทางเดียว) ผลลบจากชุด test จึงหักล้างสมมติฐานไม่ได้ ผลบวกเท่านั้นที่มีความหมาย
- **15m วัดไม่ได้** — ไม่มีชุด split และตัวเก็บแท่ง 15m ล้มมาตั้งแต่ 8 ก.ย. (แก้แล้วใน `d68b420` ยังไม่ push)
