## คำตอบสั้น ๆ

**ไม่มีกฎข้อไหนรอด** — ทั้ง 50 การทดสอบไม่มีช่องไหนที่ค่าเฉลี่ย R เป็นบวก
แล้วผ่านเกณฑ์ Holm-Bonferroni ที่ alpha 0.05

ที่สำคัญกว่านั้น: **ไม่ต้องรอถึงขั้น Holm ก็ไม่มีตัวไหนรอดอยู่แล้ว**
ช่องที่ค่าเฉลี่ยเป็นบวกมี 9 ช่อง
และ p ดิบที่น้อยที่สุดในกลุ่มนั้นคือ 0.3834
ซึ่งยังห่างจาก 0.05 มาก การแก้ multiple testing จึงไม่ได้ "ฆ่า" อะไรที่มีชีวิตอยู่ก่อน
— มันแค่ยืนยันว่าไม่มีอะไรให้ฆ่าตั้งแต่แรก

สิ่งที่ผ่านเกณฑ์ Holm จริง ๆ มี 14 ช่อง แต่ทั้งหมดเป็น
**กฎที่ขาดทุนอย่างมีนัยสำคัญ** (14 ช่อง) ไม่ใช่กฎที่ทำกำไร

## วิธีอ่านตัวเลขในตาราง

- **R เฉลี่ย** = กำไร/ขาดทุนสุทธิต่อไม้ หน่วยเป็นเท่าของเงินที่เสี่ยง หักต้นทุนแล้ว
- **CI 95%** มาจาก bootstrap 100,000 รอบ สุ่มเป็นก้อนตาม symbol (13 ก้อน)
  ไม่ใช่สุ่มราย-ไม้ เพราะไม้ใน symbol เดียวกันไม่เป็นอิสระต่อกัน
- **p ดิบ** = p สองหางจาก bootstrap ก้อนเดียวกัน ละเอียดได้แค่ 1e-5
  ค่าที่แสดงเป็น `< 1e-5` คือค่าที่ bootstrap ตอบว่า 0 ซึ่งอ่านว่า "น้อยกว่า 1e-5" ไม่ใช่ศูนย์จริง
  ก่อนเข้า Holm ค่าพวกนี้ถูกยกพื้นไว้ที่ 1e-5 เพื่อไม่ให้ adjusted p กลายเป็น 0
- **p หลัง Holm** = adjusted p แบบ step-down ที่ตัวหารสะท้อนครอบครัว 50 การทดสอบ
  ตัวที่ p น้อยที่สุดถูกคูณ 50 ตัวถัดไปคูณ 49 ไล่ลงไป และถูกบังคับให้ไม่ลดลงตามอันดับ
  ปฏิเสธ H0 เมื่อ adjusted p ≤ 0.05
- **รอด** = ผ่าน Holm **และ** R เฉลี่ยเป็นบวก — สองเงื่อนไข ไม่ใช่เงื่อนไขเดียว

## สิ่งที่ผลนี้ยังไม่ได้พิสูจน์

### 1. ไม่ได้แตะชุด test เลย — และนั่นแปลว่ายังไม่มีการยืนยันนอกกลุ่มตัวอย่าง

ทุกตัวเลขมาจาก train + validation เท่านั้น (1D ใช้แท่งก่อน 2021-08-06,
1H ใช้แท่งก่อน 2026-02-17) ชุด test ถูกตัดทิ้งตั้งแต่ตอนโหลดและมี guard ที่ throw
ถ้ามีแท่งหลุดเข้ามา ข้อดีคือชุด test ยังสะอาดพอจะใช้ตัดสินครั้งสุดท้ายได้
ข้อเสียคือ **ยังไม่มีใครยืนยันตัวเลขพวกนี้บนข้อมูลที่ไม่เคยเห็น** ผลที่ได้จึงเป็นได้แค่
"อะไรไม่ผ่านด่านแรก" ไม่ใช่ "อะไรใช้ได้จริง"

มีข้อยกเว้นหนึ่งข้อที่ต้องพูดตรง ๆ: บริบท 1D ที่กฎตระกูล MTF มองบนกรอบ 1H เป็นแท่ง 1D
ที่อยู่ในช่วง test ของ 1D (เพราะ 1H ย้อนได้แค่ราว 3 ปี) นี่ไม่ใช่การมองอนาคตของไม้ 1H
แต่ **ห้ามอ้างว่าชุด test ของ 1D ยังไม่ถูกแตะเลย** รายละเอียดอยู่ใน `scripts/research/report/split.json` หัวข้อ `overlaps`

จากช่วงเวลาแค่ 840 วัน — ราว 97.6 ไม้ต่อวันทั้งจักรวาล
เลขนี้ไม่ได้แปลว่ามีหลักฐานอิสระเป็นแสนชิ้น

การ bootstrap แบบก้อนตาม symbol แก้ปัญหานี้ได้แค่ครึ่งเดียว — มันจัดการความสัมพันธ์
*ข้ามสินทรัพย์* ให้ (ไม้ใน EURUSD ทั้งหมดขึ้นลงด้วยกัน) แต่ไม่ได้จัดการความสัมพันธ์
*ข้ามเวลาภายในสินทรัพย์เดียวกัน* ที่เกิดจากไม้ซ้อนกัน และก้อนมีแค่ 13 ก้อนซึ่งน้อยเกินกว่าที่
ทฤษฎี cluster bootstrap จะให้ CI ที่แม่น ให้ถือว่า CI ในตาราง **แคบกว่าความจริง** ไม่ใช่กว้างเกินไป

### 3. ไม่ได้รวมผลของการเอากฎหลายข้อมารวมกัน

ทุกแถวคือกฎเดี่ยว ๆ ที่เดินด้วยกติกาเข้า-ออกตายตัวชุดเดียวกัน (SL 1.5×ATR, RR 2.0, เพดานถือคงที่)
ผลนี้ไม่บอกอะไรเลยเกี่ยวกับ:

- กฎ A + กฎ B ทำงานพร้อมกันแล้วดีขึ้นหรือแย่ลง (กฎที่แย่เดี่ยว ๆ อาจเป็นตัวกรองที่ดีได้)
- กฎตระกูล `vetoes-*` ทั้ง 4 ข้อ ซึ่ง**วัดไม่ได้เลยในกรอบนี้**เพราะไม่ออกสัญญาณของตัวเอง
  คุณค่าของมันอยู่ที่การตัดไม้ของกฎอื่นทิ้ง ซึ่งต้องวัดแบบจับคู่ ไม่ใช่แบบเดี่ยว
- การจัดขนาดไม้ การทบต้น การจำกัดไม้พร้อมกัน — ตัวรันไม่ทำทั้งหมดนี้
  ตัวเลขที่ได้จึงเป็น "คุณภาพของสัญญาณ" ไม่ใช่ "ผลของพอร์ต"

พูดอีกแบบ: ผลนี้ตัดตัวเลือกออกได้ แต่สรุปไม่ได้ว่าระบบที่ประกอบจากกฎเหล่านี้จะแพ้ตามไปด้วย

### 4. 1H และ 1D ไม่ใช่ 15m ที่เจ้าของใช้จริง

เจ้าของเทรดบน 15m แต่ในแคชไม่มี 15m เลย เพราะแหล่งข้อมูลให้ย้อนหลังแค่ราวหนึ่งเดือน
ซึ่งสั้นเกินกว่าจะแบ่ง train/validation/test ได้ ทุกอย่างในรายงานนี้จึงเป็นการวัด
**กรอบเวลาอื่น** แล้วหวังว่าพฤติกรรมจะคล้ายกัน ซึ่งเป็นสมมติฐานที่ไม่ได้ทดสอบ

และมีเหตุผลที่จะเชื่อว่ามันไม่คล้าย — ดูคอลัมน์ต้นทุนก็ได้: บน 1D ต้นทุนกินราว 0.017 R ต่อไม้
แต่บน 1H กินราว 0.09–0.10 R เพราะ ATR ที่แคบกว่าทำให้ระยะ SL สั้นลง ต้นทุนคงที่จึงกลายเป็น
สัดส่วนที่ใหญ่ขึ้นมาก บน 15m ATR ยิ่งแคบกว่านั้นอีก ต้นทุนต่อไม้จะยิ่งกินหนักขึ้นไปอีก
ทิศทางของผลจึงน่าจะ**แย่กว่า**ที่เห็นในตาราง ไม่ใช่ดีกว่า แต่ "น่าจะ" ไม่ใช่ "วัดแล้ว"

### 5. ข้อจำกัดอื่นที่ต้องรู้

- **ต้นทุนเป็นค่าประมาณ** จากตารางค่าธรรมเนียมสาธารณะ ไม่ใช่ใบเสร็จจริงของโบรกเกอร์ที่ใช้
  ไม่มี slippage ไม่มี swap/ค่าถือข้ามคืน ไม่มีการขยาย spread ช่วงข่าว
- **ไม่มี survivorship/selection audit ของตัวกฎเอง** — กฎ 25 ข้อนี้ถูกเขียนขึ้นมาโดยคนที่เห็น
  ข้อมูลชุดนี้มาก่อนแล้ว จำนวนสมมติฐานที่ "ถูกคิดแล้วทิ้งไป" ก่อนจะเหลือ 25 ข้อนี้ ไม่มีใครนับ
  Holm แก้ได้แค่ 50 การทดสอบที่เขียนลงไฟล์แล้ว ไม่ได้แก้การทดสอบที่เกิดในหัว
- **กติกาเข้า-ออกตายตัว** เลือกไว้เพื่อให้เทียบกฎกันได้ ไม่ได้เลือกเพราะเป็นกติกาที่ดีที่สุด
  กฎที่แพ้ในตารางนี้อาจชนะภายใต้ SL/TP แบบอื่น และการไปหา SL/TP ที่ทำให้มันชนะ
  ก็คือการเพิ่มการทดสอบเข้าไปในครอบครัวอีก ซึ่งต้องเอามาหารเพิ่มด้วย
- **ไม่มีการวัดความเสถียรข้ามช่วงเวลา** — ตัวเลขเป็นค่าเฉลี่ยตลอดช่วง ไม่ได้บอกว่ากฎ
  ทำงานสม่ำเสมอหรือดีเฉพาะบางปี
